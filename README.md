# Personal Portfolio Website

## Developer
Umair Mirza

## About the Project

A responsive personal portfolio website that presents
my personal profile, technical interests, projects,
and contact information.

## Technologies

- HTML5
- CSS3
- JavaScript

## Features

- Responsive multi-page layout
- Personal profile and technical interests
- Dynamic project cards
- Interactive project details
- Client-side contact form validation
- Accessibility improvements
- Usability evaluation

## Project Structure

- `index.html` — Homepage
- `about.html` — Personal profile
- `portfolio.html` — Projects
- `project-details.html` — Project details
- `contact.html` — Contact form
- `assets/` — CSS, JavaScript, and images

## How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Run the website using Live Server.
4. Open `index.html` in your browser.

## Limitations

The contact form currently provides client-side
validation and does not deliver messages to an inbox.
